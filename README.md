# Spider Solitaire by Codex Game Studio Skill

A mobile-friendly Spider Solitaire web game built with Codex Game Studio. It includes animated card movement, real-feel dealing sounds, background music, hints, save/continue support, tutorial slides, and 1-suit / 2-suit / 4-suit difficulty modes.

## Live Demo

https://spider-solitaire-isclin.pages.dev/

## Features

- Touch-friendly 10-column Spider Solitaire layout for mobile browsers
- Full-screen start menu with difficulty selection
- Animated dragging, dealing, completed-run collection, and victory sequence
- Background music with ducking when sound effects play
- Sound effects for buttons, selection, movement, dealing, skills, completion, and victory
- Save and continue current game using localStorage
- Tutorial carousel with animated examples
- Chinese and English language setting

## Run Locally

Open `index.html` in a browser, or serve the folder with any static server:

```powershell
python -m http.server 4173
```

Then open http://127.0.0.1:4173/.
